Documentation

Tools for mapping where CRISPR-associated transposons (CAST) integrate, from tagmentation sequencing data. Each read starts in the transposon end (LE or RE) and reads out into the flanking genomic DNA; these tools trim the transposon sequence, map what remains, and report one insertion coordinate per read.

What's in the repository

FolderContents
core/ Functions shared across the apps, documented in the API reference.
apps/ecoli_profiling/ CAST integration profiling in E. coli: map_junction_insertions.py calls insertion sites, filter_donor_backbone.sh removes donor-plasmid reads, and plot_profile.sh plots the profile with gnuplot.
apps/uditas/ UdiTaS in human cells: CBCL-level library QC and junction-read salvage.
apps/chipseq/ chipseq_pipeline.sh — paired-end ChIP-seq.
legacy/ The older bbmap workflow: a Jupyter notebook and a Streamlit app.

Quick start

  1. Install everything, which also puts the tagmentation package on your Python path: 
    conda env create -f environment.yml
conda activate seqsuite
  2. Call insertion sites from a merged FASTQ: 
    python apps/ecoli_profiling/map_junction_insertions.py \
    --fastq sample_merged.fastq \
    --ref genome.fasta \
    --outdir mapped_reads \
    --donor-seq <transposon end sequence> \
    --donor-side 5p --primary-only
  3. Remove reads from the donor plasmid backbone: 
    apps/ecoli_profiling/filter_donor_backbone.sh \
    -g donor_plasmid.gb \
    -f mapped_reads/sample_merged.trimmed.fastq \
    -t mapped_reads/sample_merged.insertions.5p.tsv \
    -o mapped_reads/sample_merged.insertions.5p.nobackbone.tsv
  4. Analyze the resulting TSV in Python: 
    import pandas as pd
from core import postprocessHelpers as hp
from core import TsvMapHelperFunctions as tsvhp

tsv = pd.read_csv("mapped_reads/sample_merged.insertions.5p.nobackbone.tsv", sep="\t")
genome = hp.load_genome("genome.fasta")
hit = hp.map_guide_to_genome(my_guide, genome)[0]
print(tsvhp.percent_within_distance(tsv["ins0"], hit["start"], 100))
